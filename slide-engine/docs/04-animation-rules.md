# ④ アニメーションルール

## 原則

1. **動きは「読む順番」を示すためだけに使う**。演出のための動きは入れない。
2. **1 本のカーブ、3 つの時間**。全要素で揃えると、個々の動きではなく「デッキの質感」として感じられる。
3. **入場のみアニメーションする**。退場は即時（戻ったときにもう一度再生されるようにするため）。
4. **最終状態が静止画として完成している**。PDF/PNG 書き出しはアニメーション後の状態を使う。

## トークン

| トークン | 値 | 用途 |
|---|---|---|
| `--ease` | `cubic-bezier(.2,.7,.2,1)` | 要素の入場（速く出て、ゆっくり止まる） |
| `--ease-io` | `cubic-bezier(.65,0,.35,1)` | スライドのクロスフェード・マスク |
| `--dur` | 700ms | 要素の入場 |
| `--dur-slide` | 500ms | スライド切り替え |
| `--stagger` | 70ms | 要素ごとの時間差 |
| `--enter-delay` | 120ms | スライド切り替え開始から最初の要素まで |

最後の要素の開始時刻 = 120 + 70 × (要素数 − 1)。要素 10 個でも 0.75 秒で出始め、全体が 1.5 秒以内に収まる。

## 入場の種類（`data-anim`）

| 値 | 動き | 使う場所 |
|---|---|---|
| `up`（既定） | 28px 下から＋フェード | 見出し・本文・カード・リスト項目 |
| `left` | 40px 左から＋フェード | kicker・矢印（方向を示すもの） |
| `fade` | フェードのみ | メタ情報・表の行・グラフのラベル |
| `scale` | 94% → 100%＋フェード | 強調パネル（compare の After）・装飾 |
| `mask` | 左から右へ `clip-path` で現れる | 章番号など大きな文字 |
| `grow-x` / `grow-y` | 0 → 100% に伸びる | 棒グラフ・タイムラインの軸 |

## 順序の決め方

レンダラが `--i` を DOM の出現順に自動で振る。順番は **kicker → 見出し → リード → 本文要素（左上から右下）** になる。

## 特殊な動き

- **数値のカウントアップ**（`data-count`）: 0 → 値まで 1.2 秒、`easeOutQuart`。小数桁と桁区切り（カンマ）は元の表記に合わせる。
- **ステップ表示**（`steps: true`）: 未表示の要素は 12% の不透明度で「この先がある」ことを示し、クリックで 100% にする（400ms）。
- **タイムラインの軸**: 1.2 秒で左から描かれ、点と日付は stagger で続く。

## スライド切り替え

- `.is-active` の付け替えで 500ms のクロスフェード。スライドの位置は動かさない（横スライドは酔いやすく、内容の入場アニメーションと方向が衝突する）。

## アクセシビリティ・書き出し

- `prefers-reduced-motion: reduce` で全トランジションを無効化（カウントアップも最終値を即表示）。
- `?export` / `@media print` で全要素を最終状態に固定。
- 動画書き出し（`--video`）はブラウザの時計を止めて 1 コマずつ進めて撮るため、ブラウザで見た動きがそのまま（より滑らかに）動画になる。

## してはいけないこと

- 1 秒を超える単一の動き、バウンス・オーバーシュート、回転、3D フリップ。
- 1 枚の中で複数のカーブを混ぜること。
- テキストを 1 文字ずつ出すタイプライター演出（読む速度を奪う）。
